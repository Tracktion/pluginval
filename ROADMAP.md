# Roadmap

There are lots of ways pluginval can be improved, some of these are listed below but we're open to Discussions on others.

You can help get there by issuing PRs or [funding](FUNDING.md) development.

- [x] Integration of real-time safety checking (via rtcheck)
- [x] Improved command-line handling and json config file support
- [x] Acceptance testing using input files and reference output files
- [x] Integration with CTest
- [x] Machine-readable reports (JUnit XML and JSON)
- [x] GitHub Actions for validation and acceptance testing
- [ ] Acceptance testing: parameter automation during the render
- [ ] Acceptance testing: more comparison methods (e.g. spectral)
- [ ] Acceptance testing: multiple tests in one config file
- [ ] Improved stack trace/crash reporting
- [ ] Automatic integration of Asan/Tsan on platforms that allow it
- [ ] More tests/logging
- [ ] Integration of real-time safety checking (via RTSan)
